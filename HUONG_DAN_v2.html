Chạy CVAT, Label và kiểm tra QA/QC

Hướng dẫn đầy đủ để tải dự án, khởi động Docker, tạo task, label và dùng model trọng tài QA/QC.

A. Chuẩn bị máy

Cài hai phần mềm sau trước khi bắt đầu:

  • Git để tải source code.
  • Docker Desktop; mở Docker Desktop và chờ trạng thái Engine running.
Lần chạy đầu cần Internet để tải Docker image và model YOLO-BDD100K. Không cần tự tải file best.pt.

B. Clone dự án và chạy CVAT

Mở PowerShell/Terminal và chạy lần lượt:

git clone https://github.com/NhatTruong1905/cvat-project-v2.git cd cvat-project-v2 git checkout develop docker compose up -d

Docker sẽ tự build CVAT có QA/QC, tải model trọng tài và chạy prediction trên bộ ảnh demo. Kiểm tra trạng thái bằng:

docker compose ps -a docker compose logs -f model_qc_pipeline

Khi log model kết thúc và các dịch vụ cvat_server, cvat_ui ở trạng thái Up, mở:

http://localhost:8080
Lần đầu có thể mất nhiều phút tùy tốc độ mạng và máy. Các lần sau dùng model/prediction trong Docker volume nên nhanh hơn.

C. Tạo tài khoản và task demo

  1. Ở trang CVAT, chọn Create an account, đăng ký rồi đăng nhập.
  2. Vào Tasks → dấu + → Create new task.
  3. Đặt tên task, ví dụ MVP-QC-BDD100K-100.
  4. Trong Labels, chọn chế độ Raw. Mở file data/bdd100k_mvp_100_seed42/cvat_labels_raw.json, copy toàn bộ nội dung vào Raw và lưu.
  5. Ở phần dữ liệu, tải file data/bdd100k_mvp_100_seed42/bdd100k_mvp_100_seed42_images.zip rồi tạo task.
  6. Chờ task xử lý xong và trạng thái không còn Queued.

Import prelabel YOLOv8n

  1. Tại task, chọn Actions → Upload annotations.
  2. Format: Ultralytics YOLO Detection 1.0.
  3. Chọn data/bdd100k_mvp_100_seed42/model_outputs/prelabels_yolov8n_cvat_v2.zip.
  4. Chờ import hoàn tất rồi nhấn Open.
Chỉ ảnh, danh sách class và prelabel được lưu trên Git. Model trọng tài và prediction được Docker tự quản lý, annotator không phải import.

D. Quy trình annotate 3 bước

1Label hoặc sửa box
2Save rồi nhấn QA/QC
3Chọn “Chỉ lỗi” và xử lý
Annotator không cần chạy model, không cần import prediction trọng tài và không cần xem Ground Truth.

1. Mở công việc hằng ngày

  1. Mở http://localhost:8080 và đăng nhập.
  2. Vào Tasks, mở task được giao.
  3. Nhấn Open để vào màn hình annotation.
Chỉ làm đúng task/job được giao. Không thay đổi labels hoặc cấu hình task.

2. Label ảnh

  • Kiểm tra các box prelabel có sẵn.
  • Sửa box lệch, sửa class sai, xóa box không có vật thật và vẽ thêm vật bị thiếu.
  • Nhấn Save trước khi chạy QA/QC.

Checklist trước khi Save

  • Box ôm đúng vật thể.
  • Class đúng.
  • Không bỏ sót vật thể cần gán.
  • Không có hai box trùng cùng một vật.

3. Dùng QA/QC

  1. Nhấn nút QA/QC trên thanh công cụ.
  2. Chờ thông báo kiểm tra hoàn tất.
  3. Danh sách hiển thị risk thuộc nhóm frame ưu tiên theo điểm PD.
  4. Nhấn số Frame hoặc nút Chỉ lỗi.
  5. CVAT chuyển tới đúng frame và phủ vùng sọc đỏ tại vị trí cần kiểm tra.
RiskCần kiểm traCách xử lý
DROPCó thể thiếu objectNếu có vật thật, vẽ thêm box.
FLIPCó thể sai classQuan sát ảnh và đổi class nếu cần.
SHIFTBox có thể bị lệchChỉnh box ôm sát vật thể.
SPAWNBox người vẽ có thể không tồn tạiXóa nếu là box thừa; giữ nếu vật thể có thật.

4. Xác nhận cảnh báo

  • Nếu cảnh báo đúng: sửa annotation, Save, sau đó chọn Confirm.
  • Nếu annotation đã đúng và model cảnh báo nhầm: chọn False alarm.
  • Sau khi sửa, nhấn Kiểm tra lại frame để cập nhật risk.
Luôn tin vào ảnh và guideline của dự án. Model chỉ là trọng tài hỗ trợ, không phải Ground Truth.

5. Kết thúc job

  • Đã Save thay đổi cuối cùng.
  • Đã xử lý các risk được QA/QC đưa ra.
  • Không còn cảnh báo đúng nhưng chưa sửa.
  • Đã chuyển trạng thái job theo quy trình của nhóm.

Khi gặp lỗi

Trang chưa mởChạy docker compose ps -a; model lần đầu phải chạy xong thì server mới khởi động.
Model pipeline lỗiKiểm tra Internet rồi chạy docker compose up -d lại.
Không thấy nút QA/QCRefresh cứng bằng Ctrl + F5.
Task bị Queued lâuKiểm tra docker compose ps, đặc biệt worker import.
Không có riskSave frame, sau đó nhấn Kiểm tra lại frame.
“No referee predictions”Chạy docker compose logs model_qc_pipeline và báo người quản trị.
Vùng đỏ không đúngChọn False alarm và tiếp tục theo ảnh thật.
